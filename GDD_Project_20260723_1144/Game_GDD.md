# 게임 기획서: 실험실 회피 사격 보스전

## 1. 게임 개요
- 한 줄 소개: 중간 크기의 사각형 실험실에서 플레이어 1종이 보스 1종의 공격을 빠르게 피하고, 빈틈에 3단 콤보 사격으로 반격하는 TPS 보스전 게임.
- 장르: TPS 보스전 액션.
- 플랫폼: PC.
- 엔진: Unreal Engine 5.8.
- 예상 플레이 시간: 3분 내외의 짧은 보스전 1회.

## 2. 제작 범위
- 팀 규모: 1인 개발.
- 제작 기간: 4주.
- 제작자의 Unreal 숙련도: 초보.
- 개발 방식: 바이브 코딩 활용.
- 최종 제출물: 플레이 가능한 프로토타입.
- 구현 가능한 범위 요약: 플레이어 1종, 보스 1종, 중간 크기 사각형 실험실 1개, 기본 HUD, 승리/패배 흐름을 갖춘 단일 보스전.

## 3. 핵심 플레이
- 플레이어가 가장 자주 하는 행동: 보스의 공격을 보고 구르기 또는 대쉬로 피한 뒤, 짧은 반격 기회에 사격한다.
- 플레이 감각: 빠르게 피하고 반격하는 느낌.
- 기본 플레이 흐름:
  1. 보스가 플레이어를 추적하거나 공격을 준비한다.
  2. 플레이어는 보스의 공격 타이밍을 보고 구르기 또는 대쉬로 피한다.
  3. 회피 후 생긴 빈틈에 3단 콤보 사격을 넣는다.
  4. 보스 체력을 모두 깎으면 승리하고, 플레이어 체력이 0이 되면 패배한다.

## 4. 조작
- 이동: 키보드 WASD.
- 시점/카메라: 마우스로 3인칭 숄더뷰 TPS 카메라 조작.
- 사격: 마우스 왼쪽 버튼.
- 조준: 마우스 오른쪽 버튼 또는 기본 TPS 조준 방식.
- 회피: Space 또는 Shift 키를 사용한 구르기/대쉬.
- 재장전: R 키.

## 5. 규칙과 목표
- 성공 조건: 보스 체력을 0으로 만들면 승리.
- 실패 조건: 플레이어 체력이 0이면 패배.
- 플레이어 체력: 기본값 100.
- 보스 체력: 기본값 300.
- 대쉬/구르기 쿨타임: 기본값 1.2초.
- 3단 콤보 사격 피해량: 1타 10, 2타 15, 3타 25.
- 보스 기본 공격 피해량: 20.
- 탄창: 기본값은 구현 중 조정하며, HUD에 현재 총알 개수와 최대 탄창 수를 표시한다.
- 수치 조정 원칙: 체력, 피해량, 쿨타임, 탄창 크기, 보스 공격 간격은 나중에 쉽게 수정 가능한 값으로 둔다.

## 6. 콘텐츠 목록
- 플레이어: 1종. 3인칭 이동, 조준, 사격, 구르기 또는 대쉬, 피격, 사망 기능을 가진 캐릭터.
- 보스: 1종. 플레이어를 추적하고 1~2개의 공격 패턴을 사용하는 적.
- NPC: 없음.
- 아이템: 없음.
- 장애물: 없음.
- 상호작용 오브젝트: 없음.

## 7. 레벨/맵
- 공간 구성: 중간 크기의 사각형 실험실.
- 시작 지점: 플레이어는 실험실 한쪽 끝에서 시작한다.
- 보스 위치: 보스는 실험실 중앙 또는 반대편에서 시작한다.
- 주요 구역: 평평한 전투 공간 1개.
- 종료 지점: 별도 탈출 지점 없이 승리/패배 화면으로 종료한다.
- 맵 설계 의도: 장애물 없이 보스 패턴, 회피 타이밍, 사격 콤보에 집중하게 만든다.

## 8. UI
- 시작 화면: 게임 시작 버튼 또는 바로 전투 시작.
- 플레이 화면 HUD:
  - 플레이어 체력.
  - 보스 체력.
  - 대쉬/구르기 쿨타임.
  - 콤보 단계.
  - 총알 개수/탄창.
- 결과/종료 화면:
  - 승리: 보스 처치 성공 문구.
  - 패배: 플레이어 사망 문구.
  - 다시 시작 안내.
- 필요한 안내 문구: 최소한의 조작 안내만 사용한다.

## 9. 아트/사운드
- 아트 방향: 기본 에셋, 무료 에셋, 임시 에셋 중심의 SF 실험실 분위기.
- 사용할 에셋: Unreal 기본 캐릭터/머티리얼, 무료 캐릭터 또는 임시 메시, 기본 파티클.
- 필요한 사운드:
  - 사격음.
  - 피격음.
  - 대쉬/구르기 효과음.
  - 보스 공격 예고음.
  - 승리/패배 효과음.
- 대체 가능한 요소: 최종 아트 완성도보다 전투 판정, 조작감, UI 가독성을 우선한다.

## 10. 구현 우선순위
### 반드시 구현
- TPS 기본 이동.
- 3인칭 숄더뷰 카메라.
- 조준과 기본 사격.
- 대쉬 또는 구르기.
- 3단 콤보 사격.
- 플레이어 체력.
- 보스 체력.
- 보스 기본 추적.
- 보스 공격 1~2종.
- 승리/패배 처리.
- 플레이어 체력, 보스 체력, 대쉬 쿨타임, 콤보 단계, 탄창 HUD.

### 가능하면 구현
- 보스 공격 예고 표시.
- 사격, 피격, 회피 효과음.
- 콤보 단계별 시각 피드백.
- 간단한 시작 화면.
- 간단한 결과 화면.

### 시간이 남으면 구현
- 추가 보스 패턴.
- 카메라 흔들림.
- 전투 시작/종료 연출.
- 실험실 배경 디테일.

## 11. 제외할 것
- 멀티플레이.
- 스토리 컷신.
- 여러 무기.
- 여러 스테이지.
- 복잡한 인벤토리.
- 복잡한 성장 시스템.
- 정교한 보스 애니메이션 세트.
- 회복 아이템이나 특수 아이템.

## 12. 개발 일정
- 1주차: 프로젝트 세팅, TPS 이동, 카메라, 조준, 기본 사격 구현.
- 2주차: 대쉬 또는 구르기, 3단 콤보 사격, 보스 기본 추적과 공격 구현.
- 3주차: 체력, 승리/패배, HUD, 보스 체력바, 탄창 표시 구현.
- 4주차: 난이도 수치 조정, 효과음/임시 연출 추가, 버그 수정, 제출용 빌드 준비.
- 마감 전 점검: 전투가 처음부터 끝까지 끊기지 않고 진행되는지, 승리/패배가 정상 작동하는지, UI 수치가 실제 게임 상태와 맞는지 확인한다.
