# Rule Origins

## 목적

이 문서는 규칙별 출처(원인 실패, 설계 의도, 통합 이력)를 보관하는 장부입니다.

- 평소 작업에서는 읽지 않습니다. 규칙을 추가·수정·삭제하거나 재검증할 때만 참조합니다.
- 기록 절차는 `docs/HARNESS.md`의 `규칙 추가 판단`을 따릅니다.

## 출처 유형

- `실패`: 실제 실패에서 나온 규칙
- `예방`: 실패 없이 예측으로 추가 — 모델 세대가 바뀌면 재검증(규칙을 빼고 작은 task로 재현 시도) 우선 대상
- `설계`: 의도적 설계 결정
- `에이전트 제안`: 에이전트가 작성해 준 규칙 — 재검증 후보
- `통합`/`감사`/`이력`: 문서 정리 과정의 결정 기록
- `기억 안 남`: 출처 미상 — 재검증 최우선 대상
