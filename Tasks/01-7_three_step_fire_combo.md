# Task 01-7 - 3단 사격 콤보

## 설명
좌클릭 연속 사격을 1타, 2타, 3타로 이어지는 3단 콤보로 관리한다. 각 콤보 단계는 조정 가능한 기본 피해량 값을 가지며, 입력 간격 같은 콤보 끊김 조건에 따라 다음 좌클릭이 이어질 단계 또는 1타 시작 여부가 결정되어야 한다.

## 구현 항목
- [x] 좌클릭 사격이 현재 콤보 단계에 따라 1타, 2타, 3타로 구분된다.
- [x] 콤보 단계별 피해량 기본값을 1타 10, 2타 15, 3타 25로 둔다.
- [x] 콤보 단계별 피해량은 Blueprint 또는 Details 패널에서 조정 가능하다.
- [x] 콤보가 끊기는 입력 간격 값을 둔다.
- [x] 입력 간격 안에 좌클릭이 들어오면 다음 콤보 단계로 이어진다.
- [x] 입력 간격을 지나 좌클릭이 들어오면 1타부터 다시 시작한다.
- [x] 3타 이후 다음 좌클릭은 콤보 리셋 규칙에 따라 1타부터 시작한다.
- [x] 현재 콤보 단계 값은 이후 HUD에서 표시할 수 있도록 참조 가능하다.
- [x] 기존 조준, 사격 방향, 명중 판정 흐름은 유지한다.

## 범위 밖
- 공격 애니메이션 몽타주 재생
- Anim Notify 기반 콤보 입력 허용 구간
- HUD 표시 구현
- 실제 피해 적용 시스템 구현
- 적 체력 감소 또는 피격 반응
- 탄창, 장전, 탄약 소모
- 사격 이펙트, 사운드, 카메라 연출의 최종 품질 작업

## 사전 전제
- 01-5 단계의 좌클릭 기본 사격 명중 판정이 동작한다.
- 01-6 단계의 Wraith 메시와 기본 이동 로코모션 구성이 유지되어 있다.

## 수동 작업
- 필요하면 `BP_PlayerCubeCharacter`의 Details 패널에서 `Combat|Combo` 값의 1타, 2타, 3타 피해량과 콤보 리셋 시간을 조정한다.
