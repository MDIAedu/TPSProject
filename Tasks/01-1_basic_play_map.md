# Task 01-1 - 기본 플레이 맵

## 설명
장애물 없이 평평한 중간 크기 사각형 전투 공간과 플레이어 시작 지점, 보스 시작 후보 위치가 있는 동작 검증용 기본 플레이 맵을 만든다.

## 구현 항목
- [x] 사용자가 Unreal Editor에서 `Content/Maps/L_BattleMap.umap` 레벨을 직접 만들었다.
- [x] `L_BattleMap`에 플레이어 시작 위치용 `PlayerStart`가 배치되어 있다.

## 범위 밖
- 보스 로직
- 보스 시작 후보 위치 배치
- 보스 위치 확인용 임시 큐브 또는 캡슐 형상 배치
- 전투 로직
- 장애물 배치
