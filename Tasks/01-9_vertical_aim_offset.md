# Task 01-9 - 상체 세로 조준 Aim Offset

## 설명
일반 상태와 우클릭 조준 상태 모두에서 마우스 상하 움직임 또는 카메라 Pitch 값에 따라 캐릭터 상체가 정면, 위, 아래 방향을 자연스럽게 바라보도록 검증한다. 두 상태는 카메라 줌만 다르고 캐릭터 자세와 사격 모션은 동일하게 유지하며, 같은 Aim Offset 에셋을 같은 강도로 적용한다.

## 구현 항목
- [x] 일반 상태에서 카메라가 수평에 가까우면 캐릭터 상체가 정면 조준 자세를 유지한다.
- [x] 일반 상태에서 카메라가 위를 보면 캐릭터 상체가 위쪽 조준 자세로 자연스럽게 블렌드된다.
- [x] 일반 상태에서 카메라가 아래를 보면 캐릭터 상체가 아래쪽 조준 자세로 자연스럽게 블렌드된다.
- [x] 우클릭 조준 상태에서 카메라가 수평에 가까우면 캐릭터 상체가 정면 조준 자세를 유지한다.
- [x] 우클릭 조준 상태에서 카메라가 위를 보면 캐릭터 상체가 위쪽 조준 자세로 자연스럽게 블렌드된다.
- [x] 우클릭 조준 상태에서 카메라가 아래를 보면 캐릭터 상체가 아래쪽 조준 자세로 자연스럽게 블렌드된다.
- [x] 일반 상태와 우클릭 조준 상태는 카메라 줌만 다르고 캐릭터 자세와 사격 모션 차이를 만들지 않는다.
- [x] 두 상태 모두 같은 Aim Offset 에셋을 같은 강도로 사용한다.
- [x] 마우스 상하 입력 또는 카메라 Pitch 값이 Animation Blueprint로 전달되어 Aim Offset의 세로 축 값으로 사용된다.
- [x] Aim Offset 적용이 기존 이동 로코모션과 충돌하지 않는다.

## 범위 밖
- 좌우 조준 Aim Offset
- 사격 몽타주 변경
- 탄 발사 방향 또는 명중 판정 변경
- 새 사격 이펙트, 사운드, 카메라 연출
- 새 이동 로코모션 제작
- 최종 애니메이션 품질 보정

- 01-6 단계의 Wraith 메시와 기본 이동 로코모션 구성이 유지되어 있다.

## 수동 작업
- Unreal Editor에서 상체 정면, 위, 아래 조준 포즈를 사용하는 Aim Offset 에셋을 준비한다.
- Wraith Animation Blueprint를 열고 `AimPitch` 값을 Aim Offset의 세로 축 값으로 연결한다.
- 일반 상태와 우클릭 조준 상태를 나누지 말고 같은 Aim Offset 노드를 같은 블렌드 강도로 사용한다.
- Aim Offset이 기존 이동 로코모션 결과 위에 자연스럽게 섞이도록 상체 본 기준 레이어 또는 기존 애니메이션 그래프 구조에 맞게 연결한다.
- `BP_PlayerCubeCharacter`의 Mesh가 위 설정을 반영한 Wraith Animation Blueprint를 사용하고 있는지 확인한다.
