# Task 01-14 - 보스 FSM 애니메이션 상태 전환

## 설명
보스의 현재 FSM 상태에 맞춰 애니메이션 블루프린트에서 사용할 수 있는 애니메이션 상태 값이 갱신되는지 검증한다. C++ 코드는 보스의 추적, 근접 공격, 점프 내려찍기 같은 주요 FSM 상태 변화를 애니메이션 쪽에서 읽을 수 있는 형태로 전달하고, 실제 애니메이션 블루프린트 제작과 애니메이션 자산 연결은 사용자가 에디터에서 직접 진행한다.

## 구현 항목
- [x] 보스의 현재 FSM 상태가 애니메이션 블루프린트에서 참조 가능한 값으로 노출된다.
- [x] 보스가 추적 상태일 때 애니메이션 쪽 상태 값이 추적 상태로 갱신된다.
- [x] 보스가 근접 일반 공격 상태일 때 애니메이션 쪽 상태 값이 근접 공격 상태로 갱신된다.
- [x] 보스가 점프 내려찍기 공격 상태일 때 애니메이션 쪽 상태 값이 점프 내려찍기 상태로 갱신된다.
- [x] 점프 내려찍기 공격 중 점프 시작, 공중 이동, 착지 애니메이션 구간을 구분할 수 있는 값이 애니메이션 블루프린트에서 참조 가능하다.
- [x] 공격이 끝나고 보스가 다시 추적 상태로 돌아가면 애니메이션 쪽 상태 값도 추적 상태로 돌아간다.
- [x] 애니메이션 상태 전환용 C++ 변경이 기존 추적, 근접 공격, 점프 내려찍기, 플레이어 이동, 카메라 조작, 조준, 사격, 점프 흐름을 깨지 않는다.

## 범위 밖
- 보스 애니메이션 블루프린트 제작
- 보스 애니메이션 자산 선택과 연결
- 보스 메시 교체
- 애니메이션 몽타주, Anim Notify, 이펙트, 사운드 연동
- 보스 신규 공격 패턴 추가
- 보스 체력, 피격, 처치 처리

## 사전 전제
- 01-11 단계의 보스 큐브 길찾기 기반 플레이어 추적 이동이 유지되어 있다.
- 01-12 단계의 보스 FSM과 근접 일반 공격 상태 전환이 유지되어 있다.
- 01-13 단계의 보스 점프 내려찍기 공격 상태 전환이 유지되어 있다.

## 수동 작업
- Unreal Editor에서 C++ 변경 사항을 컴파일한다.
- 보스용 애니메이션 블루프린트를 만든다.
- 보스용 애니메이션 블루프린트의 부모 클래스를 `BossCubeAnimInstance`로 지정한다.
- 보스용 애니메이션 블루프린트에서 `bIsChasing`, `bIsMeleeAttacking`, `bIsJumpSlamAttacking` 값을 사용해 추적, 근접 일반 공격, 점프 내려찍기 상위 상태 전환을 구성한다.
- 점프 내려찍기 상태 안에서 `bIsJumpSlamStarting`, `bIsJumpSlamInAir`, `bIsJumpSlamLanding` 값을 사용해 점프 시작, 점프중, 착지 애니메이션 상태 전환을 구성한다.
- 보스 Blueprint의 `Boss|Jump Slam` 값에서 `JumpSlamStartAnimDuration`, `JumpSlamDuration`, `JumpSlamLandAnimDuration`을 실제 애니메이션 길이에 맞게 조정한다.
- 보스 Character 또는 보스 Blueprint의 Mesh에 사용할 보스 애니메이션 블루프린트를 연결한다.

- [ ] 보스가 근접 일반 공격을 할 때 보스 애니메이션 블루프린트의 근접 공격 상태가 활성화되는지 확인한다.
- [ ] 보스가 점프 내려찍기 공격을 할 때 보스 애니메이션 블루프린트의 점프 내려찍기 상태가 활성화되는지 확인한다.
- [ ] 점프 내려찍기 공격이 시작되면 점프 시작 애니메이션 상태가 먼저 활성화되는지 확인한다.

- [ ] 보스가 착지 지점에 도달하면 착지 애니메이션 상태가 활성화되는지 확인한다.
- [ ] `JumpSlamLandAnimDuration` 시간이 지난 뒤 보스가 추적 상태로 돌아오는지 확인한다.
- [ ] 근접 일반 공격 또는 점프 내려찍기 공격이 끝난 뒤 보스 애니메이션 블루프린트의 상태가 다시 추적 상태로 돌아오는지 확인한다.
- [ ] 보스 애니메이션 상태 전환 후에도 기존 추적, 근접 공격, 점프 내려찍기, 플레이어 이동, 마우스 카메라 조작, 우클릭 조준, 좌클릭 사격, 스페이스바 점프가 기존처럼 동작하는지 확인한다.
