# Task 01-13 - 보스 점프 내려찍기 공격

## 설명
보스가 플레이어와 일정 거리 이상 떨어져 있을 때 확률적으로 점프 내려찍기 공격을 하는지 검증한다. 점프 공격이 발동되면 발동 시점의 플레이어 위치를 착지 지점으로 고정하고, 점프 도중에는 착지 지점을 갱신하지 않는다. 착지 시에는 고정된 착지 지점을 중심으로 원형 범위 공격을 판정하며, 공격이 끝나면 보스는 다시 추적 상태로 돌아간다.

## 구현 항목
- [x] 보스와 플레이어의 거리가 발동 거리보다 멀 때 점프 공격 후보가 된다.
- [x] 점프 공격은 발동 확률에 따라 실행된다.
- [x] 점프 공격이 발동되면 발동 시점의 플레이어 위치가 착지 지점으로 고정된다.
- [x] 점프 도중 플레이어가 이동해도 착지 지점은 갱신되지 않는다.
- [x] 보스는 고정된 착지 지점으로 점프해 이동한다.
- [x] 착지 시 고정된 착지 지점을 중심으로 원형 범위 공격을 판정한다.
- [x] 플레이어가 착지 전에 판정 범위를 벗어나면 피해를 받지 않는다.
- [x] 점프 내려찍기 공격의 기본 피해량은 20으로 확인된다.
- [x] 발동 거리, 발동 확률, 점프 소요 시간, 판정 범위, 재사용 대기시간은 조정 가능한 값으로 둔다.
- [x] 점프 이동 중에는 보스와 플레이어가 겹칠 수 있도록 보스의 플레이어 충돌 응답이 Overlap 상태가 된다.
- [x] 점프 이동 중 보스와 플레이어가 겹치면 플레이어가 점프 공격 피해를 받고 보스 바깥쪽으로 밀려난다.
- [x] 착지 범위 판정으로 점프 공격 피해를 받은 플레이어도 충돌 여부와 상관없이 착지 지점 바깥쪽으로 밀려난다.
- [x] 점프 내려찍기 공격이 끝나면 보스의 플레이어 충돌 응답이 기존 Block 상태로 돌아간다.
- [x] 공격이 끝나면 보스가 다시 추적 상태로 돌아간다.
- [x] 점프 공격 흐름이 기존 추적, 근접 공격, 플레이어 이동, 카메라 조작, 조준, 사격, 점프 흐름을 깨지 않는다.

## 범위 밖
- 보스 전용 점프 애니메이션, 이펙트, 사운드
- 착지 지점 경고 표시 UI 또는 데칼
- 플레이어 체력 UI, 사망, 게임 오버 처리
- 보스 체력, 피격, 처치 처리
- 장애물 회피를 포함한 정교한 포물선 이동 보정
- 여러 단계로 나뉜 보스 패턴 선택 로직이나 최종 전투 밸런싱

## 사전 전제
- 01-11 단계의 보스 큐브 길찾기 기반 플레이어 추적 이동이 유지되어 있다.
- 01-12 단계의 보스 FSM과 근접 일반 공격 상태 전환이 유지되어 있다.
- `Content/Maps/L_BattleMap.umap`에 보스 Blueprint와 `NavMeshBoundsVolume`이 배치되어 있다.

## 수동 작업
- Unreal Editor에서 `BP_BossCubeCharacter`를 연다.
- Details 패널에서 `Boss|Jump Slam` 값을 확인한다.
- 점프 공격을 빠르게 확인하려면 `JumpSlamChance` 값을 `1.0`으로 조정한다.
- 기본 피해량 검증을 우선할 때는 `JumpSlamDamage` 값을 `20`으로 둔다.
- 필요하면 `JumpSlamTriggerDistance`, `JumpSlamDuration`, `JumpSlamDamageRadius`, `JumpSlamCooldown`, `JumpSlamArcHeight`, `JumpSlamOverlapLaunchStrength` 값을 조정한다.

- [x] 점프 중 플레이어가 이동해도 보스가 처음 고정한 착지 지점으로 이동하는지 확인한다.

- [x] 플레이어가 착지 전에 판정 범위 밖으로 벗어나면 Output Log에 `PlayerHit=false`가 표시되는지 확인한다.
- [x] 점프 이동 중 보스가 플레이어와 겹치면 Output Log에 점프 Overlap 피격 로그와 피해량 `20`이 표시되고, 착지 로그의 `PlayerHit=true`가 유지되는지 확인한다.
- [x] 점프 이동 중 보스가 플레이어와 겹칠 때 보스가 플레이어를 막고 옆으로 밀려나는 대신 플레이어가 보스 바깥쪽으로 튕겨 나가는지 확인한다.
- [x] 착지 범위 판정으로 점프 공격 피해를 받은 플레이어가 충돌 여부와 상관없이 착지 지점 바깥쪽으로 튕겨 나가는지 확인한다.
- [x] 점프 내려찍기 공격이 끝난 뒤 보스와 플레이어가 다시 서로 Block 충돌 상태로 돌아오는지 확인한다.
- [x] 점프 내려찍기 공격 후 보스가 다시 추적 상태로 돌아오는지 확인한다.
- [x] 쿨타임 중에는 보스가 점프 내려찍기 공격을 다시 즉시 사용하지 않는지 확인한다.
- [x] 점프 공격 전후로 기존 추적, 근접 공격, 플레이어 이동, 마우스 카메라 조작, 우클릭 조준, 좌클릭 사격, 스페이스바 점프가 기존처럼 동작하는지 확인한다.
