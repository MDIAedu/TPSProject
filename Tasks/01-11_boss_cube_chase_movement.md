# Task 01-11 - 보스 큐브 추적 이동

## 설명
보스 역할의 임시 큐브 또는 캡슐 형상이 플레이어 위치를 향해 길찾기 기능을 이용해 추적 이동하는지 검증한다. 이번 단계에서는 보스의 공격, 체력, 피격, 처치 흐름은 다루지 않고 추적 이동만 확인한다.

## 구현 항목
- [x] 보스 역할의 임시 큐브 또는 캡슐 형상이 플레이어를 향해 이동한다.
- [x] 보스 이동은 길찾기 기능을 이용해 검증한다.
- [x] 플레이어가 이동하면 보스가 바뀐 플레이어 위치를 향해 계속 추적한다.
- [x] 보스 추적 이동이 기존 플레이어 이동, 카메라 조작, 조준, 사격, 점프 흐름을 깨지 않는다.

## 범위 밖
- 보스 공격 패턴
- 보스 체력, 피격, 처치 처리
- 보스 전용 애니메이션, 이펙트, 사운드
- 정교한 회피, 돌진, 거리 유지 같은 추가 AI 행동
- 최종 보스 모델 또는 최종 전투 연출

## 사전 전제
- 01-1 단계의 기본 플레이 맵 구성이 유지되어 있다.
- 01-3 단계의 플레이어 Character 기반 구조가 유지되어 있다.
- 01-4 단계의 마우스 조작 3인칭 숄더뷰 카메라와 카메라 기준 이동 구성이 유지되어 있다.
- 01-10 단계의 스페이스바 점프 흐름이 유지되어 있다.

## 수동 작업
- Unreal Editor에서 `ABossCubeCharacter` 기반 Blueprint를 `Content/Blueprints` 폴더에 만든다.
- 새 Blueprint 이름을 `BP_BossCubeCharacter`로 지정한다.
- `BP_BossCubeCharacter`를 열고 `BossVisualMesh`에 임시 큐브 Static Mesh를 연결한다.
- `Content/Maps/L_BattleMap.umap`을 열고 `BP_BossCubeCharacter`를 플레이어 시작 위치에서 떨어진 지점에 배치한다.
- `L_BattleMap`에 `NavMeshBoundsVolume`을 배치하고, 플레이어와 보스가 이동할 바닥 영역을 덮도록 크기를 조정한다.
- `P` 키로 NavMesh 표시를 켰을 때 보스와 플레이어 주변 바닥에 녹색 이동 가능 영역이 보이도록 확인한 뒤 저장한다.
