# 사용자 요청

- 아래 내용을 기반으로 `docs/PLANS.md`의 작업리스트 단계 하나를 작성해줘
- 그 이후에 해당 단계의 task 파일을 새로 만들어줘
- 단, 아래 두 가지 경우에는 진행하지 말고 이유를 먼저 알려줘.
    - 이전 task 다음 순서로 오기에 적합하지 않을 때
    - 현재 task의 범위가 너무 클 때

## 원하는 동작
- 플레이어 큐브가 키보드 WASD 입력으로 실험실 안을 이동한다.

## 세부 설명
- 이동 입력은 WASD를 사용한다.
- 이 시점에는 카메라 기준 방향 이동이 아니어도 되며, 큐브가 입력대로 움직이는 것만 검증한다.
- 실제 캐릭터 모델은 아직 붙이지 않는다.
