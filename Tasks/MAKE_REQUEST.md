# 사용자 요청

- 아래 내용을 기반으로 `docs/PLANS.md`의 작업리스트 단계 하나를 작성해줘
- 그 이후에 해당 단계의 task 파일을 새로 만들어줘
- 단, 아래 두 가지 경우에는 진행하지 말고 이유를 먼저 알려줘.
    - 이전 task 다음 순서로 오기에 적합하지 않을 때
    - 현재 task의 범위가 너무 클 때

## 원하는 동작
- 연속 사격이 1타·2타·3타로 이어지는 3단 콤보로 동작한다.

## 세부 설명
- 콤보 단계별 피해량 기본값은 1타 10, 2타 15, 3타 25이며 조정 가능한 값으로 둔다.
- 콤보가 끊기는 조건(입력 간격 등)을 두고, 현재 콤보 단계를 내부적으로 관리한다.
- 콤보 단계 값은 이후 HUD에서 표시할 수 있도록 참조 가능하게 둔다.
