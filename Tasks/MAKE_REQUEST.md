# 사용자 요청

- 아래 내용을 기반으로 `docs/PLANS.md`의 작업리스트 단계 하나를 작성해줘
- 그 이후에 해당 단계의 task 파일을 새로 만들어줘
- 단, 아래 두 가지 경우에는 진행하지 말고 이유를 먼저 알려줘.
    - 이전 task 다음 순서로 오기에 적합하지 않을 때
    - 현재 task의 범위가 너무 클 때

## 원하는 동작
- 마우스 우클릭으로 조준하고 좌클릭으로 정면에 기본 사격을 한다.

## 세부 설명
- 우클릭(또는 기본 TPS 조준 방식)으로 조준 상태에 들어간다.
- 좌클릭으로 사격하며, 탄이 나가는 방향/피격 판정을 큐브 대상으로 검증할 수 있게 한다.
- 이 시점 피해량·콤보·탄창은 다루지 않고, 사격 발생과 명중 판정만 확인한다.
