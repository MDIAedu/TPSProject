# 사용자 요청

- 아래 내용을 기반으로 `docs/PLANS.md`의 작업리스트 단계 하나를 작성해줘
- 그 이후에 해당 단계의 task 파일을 새로 만들어줘
- 단, 아래 두 가지 경우에는 진행하지 말고 이유를 먼저 알려줘.
    - 이전 task 다음 순서로 오기에 적합하지 않을 때
    - 현재 task의 범위가 너무 클 때

## 원하는 동작
- 보스 큐브가 플레이어를 추적해 이동한다.

## 세부 설명
- 보스는 임시 큐브/캡슐 형상으로 플레이어 위치를 향해 추적 이동한다.
- 길찾기 기능을 이용해서 움직여야 해.
- 이 시점 공격·체력은 다루지 않고 추적 이동만 검증한다.
