# 사용자 요청

- 아래 내용을 기반으로 `docs/PLANS.md`의 작업리스트 단계 하나를 작성해줘
- 그 이후에 해당 단계의 task 파일을 새로 만들어줘
- 단, 아래 두 가지 경우에는 진행하지 말고 이유를 먼저 알려줘.
    - 이전 task 다음 순서로 오기에 적합하지 않을 때
    - 현재 task의 범위가 너무 클 때

## 원하는 동작
- 일반 상태와 우클릭 조준 상태 모두에서 마우스 상하 움직임에 따라 캐릭터 상체가 정면, 위, 아래 방향을 자연스럽게 바라본다.

## 세부 설명
- 일반 상태와 우클릭 조준 상태는 카메라 줌만 다르고 캐릭터 자세와 사격 모션은 동일하게 유지한다.
- 두 상태 모두 같은 Aim Offset 에셋을 같은 강도로 적용한다.
- 마우스 상하 입력 또는 카메라 Pitch 값을 Animation Blueprint로 전달해 Aim Offset의 세로 축 값으로 사용한다.
- 카메라가 수평에 가까우면 정면 조준 자세가 재생된다.
- 마우스를 위로 움직여 카메라가 위를 보면 상체가 위쪽 조준 자세로 블렌드된다.
- 마우스를 아래로 움직여 카메라가 아래를 보면 상체가 아래쪽 조준 자세로 블렌드된다.
- Aim Offset은 이동 로코모션과 충돌하지 않아야 한다.
- 이번 task에서는 정면/위/아래 자세 전환만 검증하고, 좌우 조준, 사격 몽타주, 탄 발사 판정 변경은 다루지 않는다.
