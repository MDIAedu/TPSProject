# Task 01-10 - 스페이스바 점프

## 설명
스페이스바 입력을 누르면 플레이어 캐릭터가 점프하고, 점프 중에는 지상 이동 로코모션에서 벗어나 공중에 있는 단일 모션으로 보이도록 검증한다.

## 구현 항목
- [x] 스페이스바 입력을 누르면 플레이어 캐릭터가 점프한다.
- [x] 플레이어 캐릭터가 지상에 있을 때만 정상적으로 점프를 시작한다.
- [x] 점프 중에는 공중에 있는 단일 모션이 표시된다.
- [x] 착지하면 기존 지상 이동 로코모션으로 돌아온다.
- [x] 점프 동작이 기존 WASD 이동, 마우스 카메라 조작, 우클릭 조준, 좌클릭 사격 콤보 흐름을 깨지 않는다.

## 범위 밖
- 이중 점프, 대시, 회피 같은 추가 공중 액션
- 점프 높이별 애니메이션 블렌딩
- 점프 시작, 상승, 하강, 착지로 나뉜 세부 애니메이션 상태
- 점프 이펙트, 사운드, 카메라 연출
- 공중 사격 전용 동작
- 최종 애니메이션 품질 보정

## 사전 전제
- 01-2 단계의 WASD 이동 입력 구성이 유지되어 있다.
- 01-4 단계의 마우스 조작 3인칭 숄더뷰 카메라와 우클릭 조준 상태가 유지되어 있다.
- 01-6 단계의 Wraith 메시와 기본 이동 로코모션 구성이 유지되어 있다.
- 01-7, 01-8 단계의 좌클릭 3단 콤보 사격 흐름이 유지되어 있다.

## 수동 작업
- Unreal Editor에서 `Content/Input` 폴더에 점프용 Input Action을 만든다.
- 점프용 Input Action은 버튼 입력으로 사용할 수 있게 설정한다.
- `Content/Input/IMC_PlayerCube`를 열고 점프용 Input Action에 `Space Bar` 키를 매핑한다.
- `BP_PlayerCubeCharacter`를 열고 `JumpAction` 값에 점프용 Input Action을 연결한다.
- 플레이어 Animation Blueprint를 열고 `bIsInAir` 값이 `true`일 때 공중에 있는 단일 모션이 재생되도록 상태 전환을 연결한다.
- 공중 상태가 끝나 `bIsInAir` 값이 `false`가 되면 기존 지상 이동 로코모션으로 돌아오도록 연결한다.
