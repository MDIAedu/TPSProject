# Task 01-12 - 보스 근접 일반 공격 상태

## 설명
기존 추적 기능이 있는 보스를 FSM 형태로 바꾸고, 플레이어가 근접 사거리 안에 들어오면 일반 공격 상태로 전환되는지 검증한다. 공격이 끝나면 보스는 다시 추적 상태로 돌아가며, 이번 단계에서는 보스 공격의 기본 피해량과 사거리, 재사용 대기시간 값을 확인할 수 있게 둔다.

## 구현 항목
- [x] 보스가 추적 상태와 일반 공격 상태를 구분한다.
- [x] 보스와 플레이어의 거리가 근접 사거리 이하가 되면 보스가 일반 공격 상태로 전환된다.
- [x] 보스 일반 공격의 기본 피해량은 20으로 확인된다.
- [x] 보스 일반 공격의 사거리와 재사용 대기시간은 조정 가능한 값으로 둔다.
- [x] 일반 공격이 끝나면 보스가 다시 추적 상태로 돌아간다.
- [x] 보스 근접 공격 흐름이 기존 플레이어 이동, 카메라 조작, 조준, 사격, 점프 흐름을 깨지 않는다.

## 범위 밖
- 보스 체력, 피격, 처치 처리
- 플레이어 체력 UI, 사망, 게임 오버 처리
- 보스 공격 전용 애니메이션, 이펙트, 사운드
- 콤보 공격, 원거리 공격, 광역 공격 같은 추가 공격 패턴
- 정교한 공격 판정 보정이나 최종 전투 밸런싱

## 사전 전제
- 01-11 단계의 보스 큐브 길찾기 기반 플레이어 추적 이동이 유지되어 있다.
- `Content/Maps/L_BattleMap.umap`에 보스 Blueprint와 `NavMeshBoundsVolume`이 배치되어 있다.

## 수동 작업
- Unreal Editor에서 `BP_BossCubeCharacter`를 연다.
- Details 패널에서 `Boss|Melee Attack` 값을 확인한다.
- 필요하면 `MeleeAttackRange`, `MeleeAttackCooldown`, `MeleeAttackDamage`, `MeleeAttackDuration` 값을 조정한다.
- 기본 피해량 검증을 우선할 때는 `MeleeAttackDamage` 값을 `20`으로 둔다.
